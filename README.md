## 👨‍💻 Executive Biography

I am **Basi Ibnumoideen**, a **Full Stack MERN Developer** and **Roblox Systems Engineer** currently pursuing my degree in Software Engineering at **Regional College Mundamparamba** in Areekode, Kerala, India.

My engineering philosophy centers around **Clean Architecture**, modular code organization, scalable data models, and deliberate product design. In web development, I leverage the **MERN stack (MongoDB, Express.js, React, Node.js)** alongside **JavaScript** and modern tooling to build high-performance web applications featuring resilient **REST APIs**, robust authentication flows, and responsive UI components.

Simultaneously, I specialize in **Roblox Game Development** using **Luau (Lua)**, designing decoupled server-client event networks, state-driven UI clients, procedural environment systems, and persistent in-game economies using `DataStoreService`. I actively integrate **AI-augmented development methodologies** into my workflow, utilizing tools like LLMs and Model Context Protocol (MCP) implementations for accelerated feature prototyping, live in-engine debugging, and continuous integration.
